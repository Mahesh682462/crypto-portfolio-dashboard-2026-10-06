# Crypto Portfolio Dashboard

A simple, single-page application built with HTML, CSS, and JavaScript that displays mock cryptocurrency portfolio data.

## Features

- Displays coin name, current price, 24h change, your holdings, and total value.
- Simulates real-time updates of prices and 24h changes every few seconds.

## How to Run

1. Save all files (`index.html`, `style.css`, `script.js`) into the same directory.
2. Open `index.html` in your web browser.

The dashboard will automatically populate with mock data and start updating.
